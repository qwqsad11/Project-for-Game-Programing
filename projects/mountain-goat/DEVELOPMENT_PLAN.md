# 《石山羊》Unity复刻项目计划

## 📋 项目概述
- **目标**：使用Unity完整复刻《石山羊》手机游戏
- **预计周期**：4-6周（根据团队规模调整）
- **平台**：iOS / Android
- **引擎**：Unity 2020 LTS 或更高

---

## 🏗️ Phase 1：基础架构（第1周）

### 1.1 项目初始化
- [ ] **创建Unity项目**
  - 标签：`setup`
  - 优先级：🔴 Critical
  - 描述：初始化Unity项目，选择2D模板，配置iOS/Android平台设置
  - 子任务：
    - [ ] 创建基础文件夹结构（Scripts, Prefabs, Scenes, Art, Audio等）
    - [ ] 导入必要的包（TextMesh Pro, 输入系统等）
    - [ ] 配置Player Settings（包名、图标、启动场景等）

### 1.2 核心游戏管理器
- [ ] **GameManager脚本**
  - 标签：`core-system` `architecture`
  - 优先级：🔴 Critical
  - 描述：全局单例管理器，控制游戏流程、状态、分数等
  - 子任务：
    - [ ] 实现单例模式
    - [ ] 游戏状态机（MenuState, PlayingState, GameOverState, PausedState）
    - [ ] 分数和高分管理
    - [ ] 暂停/恢复逻辑

### 1.3 场景管理
- [ ] **场景结构搭建**
  - 标签：`setup` `scene`
  - 优先级：🔴 Critical
  - 描述：创建主菜单、游戏场景、结果界面
  - 子任务：
    - [ ] 主菜单场景布局
    - [ ] 游戏主场景（山体）
    - [ ] 游戏结束UI场景

## 🐐 Phase 2：玩家角色系统（第1-2周）

  - 描述：实现山羊左右跳跃的核心机制
  - 子任务：

    - [ ] 编写跳跃动画和声效反馈

### 2.2 山羊模型与动画

### 2.3 山羊多皮肤系统
- [ ] **角色皮肤切换**

## 🏔️ Phase 3：山体与关卡生成（第2-3周）

### 3.1 棋盘式地形生成
- [ ] **动态关卡生成器**
  - 标签：`gameplay` `procedural`
  - 优先级：🔴 Critical
  - 描述：实现棋盘式山体，支持前后深度方向
  - 子任务：
    - [ ] 创建Platform预制体（立方体格子）
    - [ ] LevelGenerator脚本（无限向上生成）
    - [ ] 实现X-Z轴坐标系（X左右，Z前后）
    - [ ] 清理离视场过远的平台（优化性能）

### 3.2 地形障碍物
- [ ] **基础障碍物系统**
  - 标签：`gameplay` `obstacles`
  - 优先级：🔴 Critical
  - 描述：实现5种主要障碍物
  - 子任务：
    - [ ] **圆木**（RollingLog）- 沿直线滚动
    - [ ] **落石**（FallingRock）- 下落+随机变向
    - [ ] **雷云**（LightningCloud）- 周期性释放闪电
    - [ ] **碎石路**（CrumblingPlatform）- 踩踏后延迟崩塌
    - [ ] **河流/断崖**（Gap）- 无法跨越的空白

### 3.3 碰撞检测
- [ ] **伤害和碰撞系统**
  - 标签：`gameplay` `physics`
  - 优先级：🔴 Critical
  - 描述：检测山羊与障碍物碰撞，触发死亡
  - 子任务：
    - [ ] 设置物理层（Player, Platform, Obstacle, Trigger等）
    - [ ] 实现OnTriggerEnter检测
    - [ ] 死亡反馈（音效、动画、墓碑显示）
    - [ ] 无敌状态处理（使用道具时）
