# Mountain Goat Project

This folder contains the Mountain Goat Unity project as a standalone project inside the repository.

## Open in Unity

Open `projects/mountain-goat/` directly in Unity Hub instead of opening the repository root.

## Main Scenes

- `Assets/Scenes/MainMenu.unity`
- `Assets/Scenes/GamePlay.unity`
- `Assets/Scenes/GameOver.unity`

## Project Layout

- `Assets/` game assets, scenes, prefabs, and scripts
- `Packages/` Unity package dependencies
- `ProjectSettings/` Unity project configuration

## Notes

- `Library`, `Temp`, `Logs`, and other generated files are ignored in this subproject
- This project is intentionally isolated from the root `Solar System Project`
